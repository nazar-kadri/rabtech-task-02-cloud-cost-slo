# RabTech Academy - Task 02

## Service Blueprint, SLOs & Cloud Cost Envelope

This repository contains my work for Task 02 of the RabTech Academy Cloud Computing & DevOps Internship.

### Work Completed

- Designed a two-tier service blueprint
- Defined request, dependency, data, deployment and failure paths
- Compared Lean, Balanced and Resilient scenarios
- Defined availability and latency SLOs
- Worked with RPO and RTO requirements
- Prepared a three-scenario cloud cost model
- Compared estimated cost and available budget
- Recorded architecture and recovery decisions
- Selected the Balanced architecture as the recommended option

### Final Decision

I selected the **Balanced Architecture** because it provides a practical balance between availability, performance, recovery requirements and monthly cost.

### Architecture

The Balanced design uses:

- Load Balancer
- Two application instances across different Availability Zones
- Primary and Standby Database
- Backup and Recovery
- Monitoring and Alerting
